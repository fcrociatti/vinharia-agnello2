# Vinheria Agnello - Checkpoint 02

Sistema de avaliação de estoque e tendência de vinhos da Vinheria Agnello.

## Sobre o projeto

Projeto desenvolvido como Checkpoint 02 da disciplina de Web Development do curso de Engenharia de Software da FIAP, turma 1ESPS.

Continuação do Checkpoint 01. Agora o sistema permite cadastrar vários vinhos em sequência (até 5), perguntando ao final de cada cadastro se o usuário quer cadastrar outro.

O que foi feito:

- Funções para validar as entradas, verificar se o estoque está baixo (menos de 5), classificar o vinho (jovem, amadurecido ou antigo) e mostrar os dados no console
- Laços de repetição com `while`, `do...while` e `for`
- Variáveis locais dentro das funções
- Resumo final com a quantidade de cadastros, quantos vinhos têm estoque baixo e o vinho com a safra mais antiga

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
